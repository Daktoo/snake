# Dakto INC Snake
This is a project for an offline version of https://games.daktoinc.co.uk/snake .
Linux executable written in C++. Windows executable written in C#.

## Requirements
The Windows and Linux both have different requirements, here is the list.
### Linux
[SFML 2.6.0](https://www.sfml-dev.org/download/sfml/2.6.0/)

### Windows
[.NET Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/9.0)
